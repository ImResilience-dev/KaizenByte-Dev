# Cryptography and BitLocker Lab

## Purpose

Document coursework and practical learning related to hashing, file encryption, key-management concepts, and BitLocker protection.

## Suggested contents

- `notes.md` — Concepts, commands, and validated observations.
- `evidence/` — Sanitized screenshots or test results.
- `mitigations.md` — Data-protection recommendations and recovery considerations.

## Safety

Never commit recovery keys, passwords, private keys, encrypted sensitive files, or real user data.
