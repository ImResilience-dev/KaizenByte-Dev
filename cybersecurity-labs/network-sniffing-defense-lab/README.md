# Network Sniffing Defense Lab

## Purpose

Study packet-capture and network-observation risks in an isolated, authorized environment, with focus on detection and mitigation.

## Suggested contents

- `notes.md` — Objectives, methodology, and findings.
- `evidence/` — Sanitized packet excerpts, diagrams, and screenshots.
- `mitigations.md` — Network controls such as segmentation, encryption, port security, monitoring, and DNS protections.

## Safety

Capture only traffic you are authorized to inspect. Redact IP addresses, hostnames, usernames, cookies, tokens, and other sensitive values before publishing artifacts.
