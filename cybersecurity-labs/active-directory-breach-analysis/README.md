# Active Directory Breach Analysis

## Purpose

Document an authorized Active Directory security lab with emphasis on identifying risks, analyzing evidence, and recommending defensive controls.

## Suggested contents

- `notes.md` — Lab observations and methodology.
- `evidence/` — Sanitized screenshots, logs, or diagrams.
- `mitigations.md` — Prioritized hardening recommendations.

## Safety

Use only test domains, accounts, hosts, and credentials created for an authorized lab. Remove personally identifiable information, credentials, tokens, and sensitive system details before committing evidence.
