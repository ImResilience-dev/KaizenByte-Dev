Coordinates use a top-left origin and exclusive right/bottom bounds. Published dimensions are 757 × 542 and 700 × 945 respectively. Cropping removes the VM toolbar and desktop challenge-file icons. E2 retains a narrow file-size column behind the tool windows, with no visible personal names or file contents. No text overlays, blur, digest edits, or reconstructed result fields were applied. The exported PNGs were visually checked after cropping.

The filenames provide capture labels only; no trusted timestamps or chain of custody are inferred. The underlying disk image and original hashes.txt were not available for independent calculation. Cropping changes the image file bytes, so publication hashes are not the hashes of the original screenshots or the forensic disk image.

[SHA256SUMS](SHA256SUMS) records SHA-256 hashes of the two published PNG files. These values identify the portfolio assets only. The report's MD5/SHA values describe the displayed lab image results and serve a separate purpose.

E1 shows all five algorithms selected. In E2 the HashCalc MD5 box is unchecked and its result field is blank. SHA-512 is clipped in both HashCalc views; the report does not claim a complete SHA-512 comparison. WordPad is a display of text, not an authenticated execution log.

Unredacted originals, credentials, challenge answers, private conversation exports, and the lab disk image are excluded from publication.
