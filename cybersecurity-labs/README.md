# Cybersecurity Labs

This directory contains authorized, educational cybersecurity labs focused on analysis, detection, hardening, and mitigation.

## Scope

All material in this repository is intended for use only in isolated lab environments, coursework, and other explicitly authorized defensive-security contexts. Do not use these materials against systems, accounts, networks, or data without written permission.

## Lab categories

- `active-directory-breach-analysis/` — Active Directory security analysis and defensive recommendations.
- `cryptography-and-bitlocker-lab/` — Hashing, file encryption, and BitLocker learning materials.
- `network-sniffing-defense-lab/` — Network-sniffing risks, detection indicators, and mitigations.
- `dos-defense-and-mitigation/` — Denial-of-service resilience and defensive planning.

Each lab should include a purpose statement, authorized lab scope, sanitized evidence, findings, and defensive controls.
